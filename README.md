# DSA Course - C++

A simple and structured **Data Structures and Algorithms course using C++**, starting from programming basics and progressing to advanced DSA concepts.

## 📚 Topics Covered

- **Programming Basics** – Variables, Data Types, Operators, Functions
- **Conditional Statements** – `if`, `else`, `else if`, `switch`
- **Loops** – `for`, `while`, `do-while`
- **Patterns** – Star and Number Patterns
- **Arrays** – Basic operations and problems
- **Searching** – Linear Search, Binary Search
- **Sorting** – Bubble, Selection, Insertion, Merge, Quick, Heap Sort
- **Recursion** – Basic recursion and recursive problems
- **Linked List** – Singly, Doubly and Circular Linked Lists
- **Stack** – Implementation and basic applications
- **Queue** – Simple, Circular and Priority Queues
- **Binary Trees** – Tree creation and traversals
- **Graphs** – Graph representation and traversal
- **BFS & DFS** – Breadth First Search and Depth First Search
- **Heap** – Min Heap, Max Heap and Heap Sort
- **Algorithms**
  - Prim's Algorithm
  - Kruskal's Algorithm
  - Dijkstra's Algorithm
  - Knapsack Problem
  - Dynamic Programming
  - Backtracking
  - And other important algorithms

## 💻 Language

All implementations are written in **C++** with a focus on understanding the concepts, logic, and implementation of DSA.

## 🎯 Goal

To provide students with a simple path to learn **Programming → Data Structures → Algorithms → Problem Solving** using C++.

> Learn → Implement → Analyze → Practice
